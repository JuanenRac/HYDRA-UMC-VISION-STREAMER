## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an industrial streaming system, a security flaw can lead to unauthorized monitoring or denial of service. If you discover a vulnerability affecting the **GStreamer pipeline**, **RTSP server**, or **camera control API**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows unauthorized stream access, buffer overflows, or remote execution.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
